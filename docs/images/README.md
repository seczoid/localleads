# README screenshots

The main README shows these images. They are 1440x900 at 1.5x (2160x1350),
dark theme, compressed with `pngquant --quality 80-95`. The Help page in the
app uses the same shots from `static/docs/` (`dashboard.png` is `hero.png`).

| File | What it shows |
| --- | --- |
| `hero.png` | The Searches page with a search running: Google Maps done, websites being read |
| `new-search.png` | The New search form with the Google Maps category list open |
| `search-live.png` | A search's page: both progress bars above its newest leads |
| `lead-detail.png` | One lead's details: emails with sources, socials, place details |
| `leads-browse.png` | The leads table with the Category filter open, showing counts |
| `proxies.png` | The Proxies page: group tabs, health bar, status and latency per proxy |
| `mcp.png` | The Agents page: API keys, then the setup command for each agent |

Use sample data only: `alex@example.com` as the account, documentation IP
ranges for proxies, and `leads.example.com` / `/var/lib/localleads` in place of
local paths and addresses.
