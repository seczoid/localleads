About scraping

LocalLeads reads Google Maps web responses directly; no API key is needed. Google can change the response format, ask for consent, rate-limit, or restrict access. Those responses are reported as search failures and are never bypassed. Collect data in line with applicable law and Google's access policies.

JSON API: /api/stats, /api/jobs, /api/jobs/<id>, /api/leads?q=&source=&limit=&offset=
