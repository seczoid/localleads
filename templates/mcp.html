Good to know

  • Agents ask before deleting anything: delete tools are marked as destructive.
  • Searches started by an agent appear under Searches like any other, with live progress.
  • Big lead lists come in pages of up to 1,000; agents export to a file for anything larger.
  • Stdio agents pass the key in LOCALLEADS_API_KEY; HTTP agents send Authorization: Bearer <key> (or X-API-Key).
  • Getting “invalid API key”? The key was revoked or mistyped. Create a new one and update the agent's config.
  • Not connecting? Restart the agent after adding the config, and check the command path above still exists.
